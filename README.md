# BudgetPlanner

Android-приложение для планирования бюджета. Главный экран отвечает на один вопрос: **сколько можно потратить сегодня**, чтобы денег хватило до следующего дохода (стипендии или зарплаты).

Аккаунта и входа нет: все данные хранятся только на телефоне, в зашифрованной базе.

## Возможности

- **«Можно сегодня».** Бюджет периода делится на оставшиеся дни с учётом трат, обязательных платежей и резерва; перерасход переносится на следующие дни.
- **Автоимпорт из уведомлений банков** (Сбер, Т-Банк, Альфа-Банк): покупки, переводы и зачисления записываются сами. Приложение читает только уведомления банковских приложений и не сохраняет их текст; SMS не читаются.
- **Черновики и категории.** Операции без категории ждут подтверждения, а правила для знакомых магазинов подставляют категорию автоматически.
- **Сверка с банком.** Остаток из уведомлений сравнивается с расчётом, корректировка только с подтверждения.
- **Статистика:** траты по категориям, по дням и сравнение с прошлым периодом.
- **ИИ-помощник** на GigaChat отвечает на вопросы о бюджете через локальные инструменты, которые только читают данные; выключен по умолчанию.
- **Виджет и напоминания:** сумма на рабочем столе, уведомления о перерасходе, платежах и доходе.
- **Защита входа** по биометрии или PIN телефона.
- **Экспорт в CSV и резервная копия** под паролем, восстановление на новом телефоне.

## Приватность

- База зашифрована SQLCipher, ключ защищён Android Keystore, база исключена из облачного бэкапа Android.
- Из сетевых разрешений только `INTERNET`, и он нужен только помощнику. Аналитики и рекламы нет.
- В модель ИИ уходят только итоги и суммы по категориям; названия магазинов можно отключить.

## Стек

Kotlin, Jetpack Compose, Material 3, Clean Architecture + MVVM, Hilt, Room + SQLCipher, DataStore, Ktor Client (OkHttp), Glance, WorkManager, Biometric, Vico. `minSdk` 29, `targetSdk` 37.

## Сборка

Нужна Android Studio 2026.1.3 или новее (Android Gradle Plugin 9.3).

1. Склонируйте репозиторий и откройте папку в Android Studio.
2. Скопируйте [`local.properties.example`](local.properties.example) в `local.properties` и укажите путь к Android SDK. Android Studio обычно создаёт этот файл сама.
3. Помощнику нужен ключ GigaChat API: впишите его в `local.properties` строкой `gigachat.authKey=…`. Без ключа приложение работает, а помощник показывает, что он не настроен. Файл `local.properties` в git не попадает.
4. Запустите конфигурацию `app` или соберите отладочную версию:

```bash
./gradlew :app:assembleDebug
```

Release-сборка подписывается вашим ключом из `keystore.properties`, подробности в [`docs/release-signing.md`](docs/release-signing.md).
