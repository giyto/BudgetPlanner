## Why

Сейчас в проекте стандартный шаблон Android Studio: экран «Hello Android», фиолетовая тема и динамические цвета системы. Все следующие этапы ТЗ (раздел 16) опираются на общий каркас: пакеты Clean Architecture, внедрение зависимостей, тему из макетов, навигацию между экранами и тесты на API 29 и 37. Без этого каркаса каждый этап начинал бы с инфраструктуры и делал бы её по-своему.

## What Changes

- Пакеты по разделу 8.2 ТЗ: `domain`, `data`, `notifications`, `ai`, `ui`, `widget`. Доменный слой остаётся на чистом Kotlin без зависимостей от Android.
- Hilt: класс `Application`, точка входа в `MainActivity`, модуль с общими зависимостями.
- Внедряемый источник времени (`Clock`) для всех будущих расчётов по датам (FR-03).
- Тема из макетов: палитра «графит и синий» для светлой и тёмной темы, шрифты Onest и Unbounded. Динамические цвета Android 12+ отключаются, чтобы приложение выглядело как на макетах.
- Каркас навигации: нижняя панель с вкладками «Главная», «Операции», «Статистика», «Помощник», кнопка «+» для новой операции и переход в настройки. Экраны пока заглушки, наполнение приходит в следующих этапах.
- Удаление шаблонного кода (`Greeting`, фиолетовые цвета, примеры тестов).
- Тестовая инфраструктура: JUnit 4, kotlinx-coroutines-test, Turbine, Compose UI Test; проверка запуска на эмуляторах API 29 и API 37.
- Версии библиотек фиксируются в `gradle/libs.versions.toml` по разделу 9.1 ТЗ.

## Capabilities

### New Capabilities
- `app-theme`: внешний вид приложения — светлая и тёмная тема по настройке системы, палитра и шрифты из макетов, минимальный размер нажимаемых элементов.
- `app-navigation`: структура экранов — нижняя панель с четырьмя вкладками, кнопка добавления операции, переход в настройки, поведение кнопки «Назад».
- `app-foundation`: общие свойства приложения — работа без интернета, единый источник текущего времени, поддерживаемые версии Android.

## Impact

- **Код:** `MainActivity`, пакет `ui/theme` переписываются; добавляются класс `Application`, граф навигации, экраны-заглушки, DI-модуль.
- **Сборка:** новые зависимости и плагины — Hilt, KSP, Navigation Compose, Lifecycle ViewModel Compose, kotlinx.coroutines, Turbine. Kotlin-плагин не подключается отдельно: AGP 9 включает поддержку Kotlin сам.
- **Ресурсы:** файлы шрифтов Onest и Unbounded в `res/font` (лицензия SIL OFL), XML-тема без ActionBar с цветом фона из палитры, чтобы при запуске не мелькал белый экран.
- **Манифест:** регистрируется класс `Application`. Разрешение `INTERNET` не добавляется до этапа `add-ai-assistant`.
- **Не затрагивается:** база данных, уведомления, ИИ, виджет — это следующие этапы.
