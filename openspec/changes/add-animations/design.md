## Context

Мотивация — в `proposal.md`, требования — в `specs/ui-motion/spec.md`. Что уже есть:

- Главная (`ui/home/HomeScreen.kt`): `HeroCard` с суммой «можно сегодня» и полоской из двух `Box` с `fillMaxWidth(progress)`; `PeriodCard` с полосой из трёх `Box` с весами и тремя суммами `PeriodNumber`; плашки (`IncomeDayBanner`, `ImportBanners.kt`, `MismatchBanner`) показываются условием `if`.
- Навигация (`ui/BudgetApp.kt`): один `NavHost` с графами вкладок и экранами поверх; переходы не заданы, Navigation Compose 2.10 по умолчанию растворяет экраны.
- Списки: `OperationsScreen` — `LazyColumn` с группами по дням (ключ — день), строки внутри группы в `Column`; `DraftsScreen` — `LazyColumn` с ключом id операции; чат помощника — `LazyColumn` с ключом id сообщения и индикатором «Считаю…» из трёх точек.
- Суммы форматируются `MoneyFormat` с неразрывными пробелами; у главной карточки одно объединённое описание для TalkBack.
- В проекте нет ни одной своей анимации; UI-тесты (166 на эмуляторах) рассчитаны на мгновенную смену состояний.

## Goals / Non-Goals

**Goals:**
- Одна точка, где решается «анимировать или нет», — с учётом системной настройки и с подменой в тестах.
- Прокрутка цифр — переиспользуемый компонент с чистой функцией разбора суммы на символы, проверяемой unit-тестом.
- Длительности и кривые в одном месте (`Motion`), чтобы движение было одинаковым по всему приложению.

**Non-Goals:**
- Анимации виджета (Glance их не поддерживает).
- Анимация суммы на клавиатуре «Новой операции» (ввод должен отзываться мгновенно) и плашек фильтров операций.
- Общие элементы между экранами (shared element), жесты предиктивного «Назад», анимированные иконки.
- Свой переключатель анимаций в настройках (решение пользователя).

## Decisions

### 1. `MotionSettings` и `LocalReducedMotion`

Интерфейс `MotionSettings { fun reduced(): Boolean }`; реализация читает `Settings.Global.ANIMATOR_DURATION_SCALE` (ставится в 0 системной «Убрать анимацию» и в настройках разработчика). Значение кладётся в `CompositionLocal` `LocalReducedMotion` в `MainActivity` и перечитывается в `onResume`. Compose сам масштабирует длительности по этой настройке, но явный флаг нужен для того, что Compose не масштабирует: бесконечной анимации точек, переходов Navigation и выбора «показать сразу» для прокрутки цифр.

В UI-тестах Hilt-модуль подменяет `MotionSettings` на «анимации выключены» (`TestStart.motion`): бесконечная анимация индикатора иначе не даёт тесту дождаться покоя. Отдельный тестовый класс включает анимации и проверяет итоговые значения после продвижения `mainClock`.

*Альтернатива:* полагаться только на масштаб Compose. Отвергнута: при масштабе 0 бесконечная анимация ведёт себя непредсказуемо, а переходы Navigation задаются отдельно.

### 2. `Motion` — длительности и кривые

Объект с константами: прокрутка цифр 300 мс, полоски 450 мс, графики 600 мс, плашки и строки 250 мс, экраны и шаги онбординга 300 мс, вкладки 200 мс; кривая `FastOutSlowInEasing`, у появления — `LinearOutSlowInEasing`. Функции `motionTween(ms)` возвращают `snap()` при `LocalReducedMotion`.

### 3. `RollingAmount` — прокрутка цифр

Строка суммы из `MoneyFormat` разбивается на символы, выровненные **справа** (разряды совпадают при смене длины числа, например 1 050 → 950). Каждый символ — `AnimatedContent` с ключом-символом: цифры при смене въезжают вертикально (направление по знаку изменения суммы), остальные символы (пробелы, «₽», «−», запятая) не анимируются. Чистая функция `RollingText.columns(old, new)` возвращает пары символов по разрядам — её проверяет unit-тест. Видимый текст скрыт от TalkBack (`clearAndSetSemantics` на родителе уже задаёт объединённое описание итоговой суммы). При первом показе `AnimatedContent` не анимирует начальное состояние.

*Альтернатива:* счётчик, пробегающий значения. Отвергнута решением пользователя: дольше и «дёргается».

### 4. Полоски — `animateFloatAsState`

Доля дневного лимита и три веса полосы периода — анимируемые значения с `Motion.BAR`. Начальное значение равно целевому (без анимации при открытии экрана).

### 5. Плашки — `AnimatedVisibility`

Каждая плашка в `AnimatedVisibility(expandVertically + fadeIn, shrinkVertically + fadeOut)`. Отдельный `animateContentSize` у колонки главной не нужен: `expandVertically` сам плавно меняет высоту, и карточки ниже сдвигаются вместе с ней.

### 6. Переходы — `NavHost` transitions

У `NavHost` задаются `enterTransition`/`exitTransition`/`popEnterTransition`/`popExitTransition`: если оба экрана — начальные экраны вкладок, то `fadeIn`/`fadeOut` 200 мс; иначе экран поверх въезжает `slideInHorizontally { it / 5 } + fadeIn`, предыдущий слегка уходит `slideOutHorizontally { -it / 10 } + fadeOut`, при «Назад» — наоборот. При `LocalReducedMotion` — `EnterTransition.None`/`ExitTransition.None`.

### 7. Статистика — анимация кольца и Vico

Кольцо (`CategoryDonut.kt`, `Canvas` с `drawArc`) получает общий множитель развёртки `Animatable(0f → 1f)`, который перезапускается при смене набора долей; каждая дуга рисуется на `sweep * progress`, начиная с верхней точки. Столбики по дням — Vico: включается его встроенная анимация появления (`animateIn = true`, сейчас выключена) с `Motion.CHART`, при reduced — выключена. Подписи и список категорий не зависят от анимации.

### 8. Онбординг — `AnimatedContent` шагов

Содержимое шага оборачивается в `AnimatedContent` с ключом-шагом: направление сдвига — по сравнению номеров шагов (вперёд — влево, назад — вправо). Отрезки `StepProgress` закрашиваются `animateColorAsState`. Нижние кнопки шага не анимируются, чтобы не прыгали под пальцем.

### 9. Списки и чат — `Modifier.animateItem()`

Строки `LazyColumn` с ключами получают `animateItem(fadeInSpec, placementSpec, fadeOutSpec)` с `Motion.ITEM`; при reduced — `null`-спеки. Внутри группы дня списка операций строки — в `Column` с `animateContentSize`, чтобы удаление строки внутри дня тоже было плавным. В чате появление нового сообщения — `animateItem` с проявлением и сдвигом; история при открытии показывается сразу (анимируются только элементы, появившиеся после первой отрисовки). Точки индикатора — `rememberInfiniteTransition` с тремя смещёнными по фазе альфами (цикл 1,2 с, меньше трёх вспышек в секунду); при reduced — статичные.

## Risks / Trade-offs

- [UI-тесты ждут покоя и зависают на бесконечной анимации] → подмена `MotionSettings` в тестах по умолчанию; отдельные тесты с анимациями используют `mainClock.autoAdvance = false` и продвигают время вручную.
- [Прокрутка цифр при смене длины числа (1 000 → 950) сдвигает разряды] → выравнивание символов справа; лишний разряд исчезает проявлением.
- [Шрифт Unbounded с разной шириной цифр — цифры «прыгают» по ширине] → у крупной суммы включаются табличные цифры (`fontFeatureSettings = "tnum"`), если шрифт их поддерживает; иначе ширина колонки берётся по самому широкому символу пары.
- [Анимация мешает быстрым действиям] → анимации только визуальные: данные и навигация меняются сразу, `animate*AsState` продолжает к последнему значению.

## Migration Plan

Схема данных не меняется. Поведение без анимаций полностью сохраняется при системной «Убрать анимацию».
