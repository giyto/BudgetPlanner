## Why

Перед версией 1.0 нужно проверить приложение целиком по критериям раздела 14 ТЗ и закрыть оставшиеся функции: экспорт, резервную копию, удаление данных.

## What Changes

- Экспорт операций в CSV за выбранный период (FR-11).
- Резервная копия в зашифрованный файл с паролем пользователя и восстановление из неё (FR-11).
- «Удалить все данные» в настройках (7.9).
- Доступность (NFR-04): озвучивание сумм полностью, крупный шрифт не ломает главный экран, смысл не передаётся только цветом.
- Производительность (NFR-01): главный экран быстрее 1 секунды, база на 50 000 операций.
- Проверка безопасности по таблице 10.2: нет логов с суммами и магазинами в release, чужие уведомления не сохраняются, бэкап исключён, ключи не в коде.
- Release-сборка: R8, подпись, версия 1.0.
- Прогон всех тестов на API 29 и API 37 и на реальном телефоне с банковским приложением (NFR-05).

## Capabilities

### New Capabilities
- `data-export`: экспорт в CSV, резервная копия и восстановление, удаление всех данных.

### Modified Capabilities
- `home-screen`: требования доступности и скорости открытия.

## Impact

- Затрагивает все слои; изменения в основном в `ui/settings`, `data`, настройках сборки.
- Открытые вопросы раздела 17: **2** (финальное название), **5** (публикация в RuStore или F-Droid и открытие исходного кода).
- **Статус:** черновик. Specs, design и tasks пишутся в начале этапа.
