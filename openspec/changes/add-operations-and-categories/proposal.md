## Why

Операции — основа всех расчётов: без них нечего показывать на главной, в статистике и помощнику. Этот этап даёт ручной ввод трат и доходов, который останется запасным способом и после автоимпорта (сценарий 5.4).

## What Changes

- Room: база, сущности и DAO операций и категорий, первая схема с экспортом для тестов миграций.
- Модель денег: суммы в копейках (`Long`), форматирование в рубли для экрана и для TalkBack.
- Операции (FR-01): создание, редактирование, удаление с отменой через snackbar в течение 5 секунд; типы «трата», «доход», «возврат», «перевод»; источник «вручную». Дата операции — сегодня или раньше, будущие даты не принимаются.
- Ручной ввод типа: переключатель «Трата / Доход / Возврат». Перевод вводится как трата с категорией «Переводы», тип «перевод» ставится сам (так перевод учитывается по FR-05).
- Категории (FR-02): набор трат по умолчанию из FR-02, набор доходов «Стипендия, Зарплата, Перевод, Подарок, Другое» (без «Возврата»: по FR-03 возврат уменьшает траты, а не увеличивает доход), свои категории с иконкой и цветом, скрытие вместо удаления для категорий с операциями.
- Экран «Новая операция» по макету `Add.dc.html` (с отличиями выше): цифровая клавиатура, частые категории, дата, комментарий. Тот же экран редактирует существующую операцию (7.4).
- Экран «Операции» по макету `Operations.dc.html`: группировка по дням, поиск, фильтр по категории и источнику (7.3).
- Признак «обязательный платёж» (FR-01) не входит: он связывает операцию с обязательным платежом и появляется вместе с платежами на этапе `add-period-and-daily-limit`.
- Управление категориями в настройках.

## Capabilities

### New Capabilities
- `operations`: учёт операций — поля, типы, ручной ввод, редактирование, удаление с отменой, список с поиском и фильтрами.
- `categories`: категории по умолчанию и свои, скрытие, выбор при вводе.

### Modified Capabilities
- `app-navigation`: кнопка «+» появляется и в разделе «Операции», нажатие на операцию открывает её редактирование, управление категориями открывается из настроек.

## Impact

- Новые зависимости: Room, Room testing.
- Пакеты `domain/model`, `domain/repository`, `domain/usecase`, `data/local`, `data/repository`, `ui/operations`.
- Шифрование базы не входит: SQLCipher подключается на этапе `add-data-protection`, поэтому схема должна открываться через `SupportOpenHelperFactory` без переделок.
