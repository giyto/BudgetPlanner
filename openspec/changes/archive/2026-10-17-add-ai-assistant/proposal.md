## Why

Пользователь хочет спрашивать о своих расходах обычным языком: «Хватит ли до стипендии, если куплю наушники за 3 000 ₽?» (задача 5 раздела 2 ТЗ, сценарий 5.7, FR-08). Раздел «Помощник» в нижней панели сейчас пустой. При этом финансовые данные не должны уходить в модель целиком: модель видит только итоги, которые посчитали локальные инструменты.

## What Changes

- Интерфейс `LlmProvider` в `domain` и реализация для GigaChat: получение токена доступа по ключу авторизации, запросы `chat/completions` с вызовом функций, разбор ошибок (сеть, неверный ключ, исчерпан лимит, слишком много запросов).
- Шесть локальных инструментов, которые только читают данные: `get_period_status`, `get_spending`, `get_spending_by_category`, `get_top_merchants`, `simulate_purchase`, `compare_periods`. Суммы уходят в модель в рублях, без номеров карт, остатков банка и текстов уведомлений.
- Цикл «вопрос → вызов функции → результат → ответ», не больше 5 вызовов инструментов на один вопрос (8.3 ТЗ).
- Раздел «Помощник» по макету `Assistant`: один диалог, который сохраняется между запусками, кнопка «Новый диалог», подсказки готовых вопросов, подпись «Посчитал по вашему бюджету» под ответом, счётчик израсходованных токенов.
- ИИ выключен по умолчанию. Включение — из раздела «Помощник» или настроек: экран показывает, какие данные уходят в модель, кнопка «Включить помощника» включает его сразу.
- Один общий ключ авторизации приложения подставляется при сборке из `local.properties` (вне git); пользователь ключ не вводит и не видит (решение пользователя).
- Настройка «Не отправлять названия магазинов»: инструмент магазинов недоступен, остальные отдают только категории и суммы.
- Учёт токенов, израсходованных на телефоне, по полю `usage` ответов. Понятные сообщения в чате при ошибке сети, исчерпанном лимите и недоступности сервиса; остальное приложение работает как раньше.
- Подсказка категорий для черновиков от модели (FR-06): кнопка «Подсказать категории» на экране черновиков, подсказка выбирается как предварительная категория и сохраняется только после подтверждения.
- Раздел «ИИ-помощник» в настройках: включение, «Не отправлять названия магазинов», израсходованные токены.
- Разрешение `INTERNET`; российский корневой сертификат НУЦ Минцифры доверяется только для доменов GigaChat.

## Capabilities

### New Capabilities
- `ai-assistant`: включение и раскрытие данных, общий ключ авторизации, чат и его история, инструменты и цикл вызовов, ограничения на передаваемые данные, учёт токенов, ошибки, раздел в настройках.

### Modified Capabilities
- `app-foundation`: требование «Работа без интернета» — появляется разрешение `INTERNET`, сеть используется только при включённом помощнике, без сети работает всё, кроме чата.
- `drafts`: на экране черновиков появляется подсказка категорий от модели при включённом помощнике.

## Impact

- Новые зависимости: Ktor Client (движок OkHttp, content negotiation), kotlinx.serialization JSON, Ktor MockEngine для тестов. Версии — из официальных источников при подключении.
- `res/raw` — корневой сертификат НУЦ Минцифры, `res/xml/network_security_config.xml` с `domain-config` для `ngw.devices.sberbank.ru` и `api.giga.chat`.
- База: версия 7, таблица сообщений чата, миграция 6 → 7.
- Пакеты: `domain/ai` (интерфейсы и модели), `ai` (цикл, инструменты), `ai/gigachat` (клиент, токен, DTO), `data/settings` (настройки ИИ), `ui/assistant`, раздел настроек, экран черновиков.
- Сборка: поле `gigachat.authKey` в `local.properties` → `BuildConfig`; без него помощник недоступен.
- Макеты: `docs/design/mockups/AiAssistant.html` (включение, пустой диалог, состояния чата, подсказка в черновиках) и раздел в `Settings.html`.
- Риски общего ключа (извлечение из APK, общий лимит бесплатного тарифа) описаны в design.md; перед публикацией приложения решение пересматривается.
- Ручная проверка на настоящей модели — с ключом, который пользователь получит в личном кабинете GigaChat и положит в `local.properties` перед сборкой.
