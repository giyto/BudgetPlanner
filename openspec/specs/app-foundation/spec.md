# app-foundation Specification

## Purpose
Общие свойства BudgetPlanner, на которые опираются все функции: поддерживаемые версии Android, работа без интернета и единый источник текущего времени.

## Requirements

### Requirement: Поддерживаемые версии Android
Приложение SHALL устанавливаться и запускаться на Android 10–17 (API 29–37).

#### Scenario: Запуск на минимальной версии
- **WHEN** приложение устанавливают на эмулятор с API 29 и открывают
- **THEN** открывается главная, приложение не падает

#### Scenario: Запуск на целевой версии
- **WHEN** приложение устанавливают на эмулятор с API 37 и открывают
- **THEN** открывается главная, приложение не падает

#### Scenario: Установка на старую версию
- **WHEN** приложение пытаются установить на Android 9 (API 28)
- **THEN** установка отклоняется системой

### Requirement: Работа без интернета
Приложение SHALL полностью работать без подключения к сети, кроме ответов ИИ-помощника. Разрешение `INTERNET` SHALL использоваться только ИИ-помощником: пока помощник выключен, приложение MUST NOT выполнять сетевых запросов.

#### Scenario: Запуск в режиме полёта
- **WHEN** на телефоне включён режим полёта и пользователь открывает приложение
- **THEN** все разделы открываются, сообщений об ошибке сети нет; в чате помощника вопрос получает сообщение «Нет соединения с интернетом»

#### Scenario: Разрешения приложения
- **WHEN** проверяется список разрешений собранного приложения
- **THEN** из сетевых разрешений есть только `INTERNET`

#### Scenario: Помощник выключен
- **WHEN** помощник выключен и пользователь пользуется приложением
- **THEN** приложение не открывает сетевых соединений

### Requirement: Единый источник текущего времени
Все функции, зависящие от текущей даты и времени, SHALL получать их из одного заменяемого источника. В тестах источник MUST подменяться фиксированной датой и часовым поясом.

#### Scenario: Фиксированная дата в тесте
- **WHEN** тест задаёт источнику времени дату 31 декабря 2026, 23:59, часовой пояс Europe/Moscow
- **THEN** код, получающий текущую дату, видит именно эту дату, а не системную

#### Scenario: Часовой пояс телефона
- **WHEN** приложение работает без подмены источника времени
- **THEN** текущая дата определяется по часовому поясу телефона
